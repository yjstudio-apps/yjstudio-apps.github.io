1. 운영자와 적용 범위

YJ Studio(Google Play 개발자명: YJ Playworks)는 캐슬 디펜스의 개인정보를 다음과 같이 처리합니다. 이 방침은 패키지 com.castledefense.sevendays의 현재 비공개 테스트 버전에 적용됩니다. 게임은 만 16세 이상을 대상으로 하며, 회원가입이나 계정 로그인 없이 기본 게임을 이용할 수 있습니다.

2. 기기에 저장하는 정보

게임 진행, 영웅·병사·장비와 성장 기록, 게임 내 재화, 출석·업적·전투 기록, 언어·소리·그래픽·자동화 설정을 기기에 저장합니다. 게임 저장과 복구, 진행 상태 유지에 사용합니다. 전투·성능·오류 기록도 기기 내부에 저장하며 개발자 서버나 외부 분석 서비스로 자동 전송하지 않습니다.

현재 버전에는 온라인 게임 계정, 공개 랭킹 또는 게임 자체의 클라우드 동기화가 없습니다. Android 시스템 백업이나 기기 이전은 운영체제와 사용자가 선택한 서비스의 설정·정책을 따릅니다.

3. 광고·결제·외부 서비스와 권한

현재 비공개 테스트에는 실제 광고 송출, 인앱 결제, 외부 게임 분석 또는 자동 충돌 보고 서비스를 활성화하지 않았습니다. 광고 ID를 사용하지 않습니다. 광고나 실제 결제를 이용할 수 없다는 안내가 표시되는 기능은 현재 활성화된 광고·결제를 의미하지 않습니다.

앱 설치·업데이트와 게임 리소스 다운로드에는 인터넷·네트워크 연결 및 Android의 다운로드 관련 백그라운드 서비스가 사용될 수 있습니다. 개발자가 게임 기록을 수집하는 기능은 아닙니다. Google Play가 플랫폼 제공을 위해 처리하는 계정·다운로드·연결 정보에는 Google 개인정보처리방침이 적용됩니다. 앱은 카메라·마이크·연락처·사진 보관함·정밀 위치 접근을 요청하지 않습니다.

개인정보처리방침을 열면 외부 브라우저를 사용합니다. 이 방침 웹사이트는 GitHub Pages에서 제공되며 IP 주소 등 표준 웹 연결 정보는 GitHub 개인정보처리방침에 따라 처리될 수 있습니다. 게임 진행을 이 웹사이트에 업로드하지 않습니다.

4. 문의로 직접 제공하는 정보

사용자가 이메일로 문의하면 발신 이메일 주소, 작성한 내용과 직접 첨부한 자료를 답변과 문제 해결에 사용합니다. 앱이 문의나 게임 로그를 자동 전송하지 않습니다. 문의에 비밀번호·결제 수단·실명 등 불필요한 개인정보를 포함할 필요가 없습니다. 문의 처리 목적을 달성해 불필요해진 자료는 삭제하며, 법령상 보관 의무가 있는 경우에는 해당 기간을 따릅니다. 개발자는 개인정보를 판매하지 않습니다.

5. 보관·삭제와 이용자의 권리

기기 기록은 사용자가 삭제할 때까지 보관합니다. 게임의 데이터 초기화는 게임 진행을 초기화하며, 기술 로그 등 모든 앱 데이터를 지우려면 Android 설정 → 앱 → 캐슬 디펜스 → 저장공간 → 데이터 삭제를 사용하거나 앱을 제거할 수 있습니다. 이 조치는 되돌릴 수 없으므로 필요한 기록을 먼저 확인하세요. 운영체제 백업 설정에 따라 데이터가 다시 복원될 수 있으며 해당 백업은 사용자가 그 서비스에서 관리해야 합니다.

개발자가 게임 계정이나 진행을 서버에 보관하지 않으므로 별도의 온라인 게임 계정 삭제 절차는 없습니다. 문의 정보에 대한 열람·정정·삭제 등 권리 요청은 아래 연락처에서 접수합니다. 아동의 개인정보를 알고 수집하지 않으며 관련 문의도 같은 연락처에서 처리합니다.

6. 변경과 연락처

현재 방침과 데이터 보안 표시는 현재 테스트의 활성 기능을 기준으로 합니다. 광고·결제·분석·온라인 서비스를 도입하거나 정보 처리 방식이 바뀌면 해당 버전 배포 전에 방침·시행일과 스토어의 데이터 보안 정보를 갱신하고 필요한 안내와 동의 절차를 제공합니다.

1. Operator and scope

YJ Studio (Google Play developer: YJ Playworks) provides Castle Defense. This policy applies to the current closed test of package com.castledefense.sevendays. The game targets ages 16 and above. Basic gameplay does not require registration or account sign-in.

2. Information stored on the device

Progress, heroes, troops, equipment, upgrades, virtual currencies, attendance, achievements, combat history and language, audio, graphics and assistance preferences are stored locally for gameplay, saving and recovery. Combat, performance and error records are also kept on the device and are not automatically uploaded to developer servers or external analytics services.

The current version has no online game accounts, public leaderboards or app-managed cloud synchronization. Android system backups and device transfers follow the operating system and selected service provider's settings and policies.

3. Advertising, payments, external services and permissions

This closed test has no active ad delivery, in-app payments, external game analytics or automatic crash-reporting service. It does not use the advertising ID. Features that display an unavailable-ad or unavailable-payment notice do not provide active advertising or payments.

Installation, updates and game-resource downloads may use the internet, network connectivity and Android background download services. These are not developer collection of game records. Google Play's handling of platform accounts, downloads and connection information is subject to the Google privacy policy. The app does not request access to the camera, microphone, contacts, photo library or precise location.

Opening this policy uses an external browser. This website is hosted by GitHub Pages. Standard website connection information such as IP addresses may be processed under the GitHub privacy statement. Game progress is not uploaded to this website.

4. Information you send in an inquiry

If you email us, we use your sender address, message and voluntarily attached materials to respond and resolve the issue. The app does not automatically send inquiries or game logs. Do not include passwords, payment details or unnecessary personal information. Unnecessary inquiry data is deleted after resolution, subject to applicable legal retention duties. The developer does not sell personal information.

5. Retention, deletion and rights

Local records remain until you delete them. The in-game reset clears gameplay progress. To remove all app data, including technical logs, use Android Settings → Apps → Castle Defense → Storage → Clear data, or uninstall the app. This removes your local records, so check anything you need first. Operating-system backups may restore records; manage those backups with their service provider.

There is no online game account to delete because the developer does not host accounts or progress. Contact us to request access, correction or deletion of inquiry information. We do not knowingly collect children's personal information; related requests can be sent to the same address.

6. Changes and contact

This policy and the store's data-safety disclosures describe the current test's active features. Before introducing ads, payments, analytics, online services or other processing changes, we will update this policy, its effective date and the store disclosures, and provide any required notices and consent options.
