1. 운영자와 적용 범위

YJ Studio(Google Play 개발자명: YJ Playworks)는 「커미션: 축구 에이전트」의 무료 베타를 제공합니다. 이 방침은 패키지 com.commission.footballagent에 적용합니다. 게임은 만 13세 이상을 대상으로 하며, 회원가입이나 계정 로그인 없이 오프라인으로 이용합니다.

2. 기기에 저장하는 정보

에이전트 이름, 커리어와 선수·구단 기록, 게임 내 재화와 계약, 저장 슬롯, 설정과 플레이 기록을 기기에 보관합니다. 게임 진행과 자동 저장·복구를 위한 정보이며, 개발자가 운영하는 서버에 자동 전송하거나 분석 서비스로 수집하지 않습니다. 에이전트 이름에 실제 이름 등 개인정보를 입력할 필요가 없습니다.

3. 백업·복원과 문의

백업 내보내기를 선택하면 사용자가 시스템 파일 선택기로 지정한 위치에 JSON 파일을 저장합니다. 백업에는 에이전트 이름과 게임 진행이 포함됩니다. 복원을 선택할 때만 사용자가 고른 파일을 읽으며, 파일 목록이나 다른 문서를 임의로 수집하지 않습니다. 클라우드 제공업체의 저장 위치를 직접 선택하면 해당 업체의 정책이 적용됩니다.

피드백 메모에는 게임 버전·모드·시즌·시드와 사용자가 작성한 내용이 포함될 수 있습니다. 메모는 기기에서 복사할 수 있으며 자동 전송하지 않습니다. 이메일로 문의하면 발신 주소와 사용자가 보낸 내용을 문의 처리에 사용합니다. 백업이나 불필요한 개인정보는 문의에 첨부하지 않아도 됩니다.

4. 광고·외부 서비스와 권한

현재 무료 베타는 실제 광고, 인앱 결제, Google Play 게임즈 로그인, 앱 자체의 클라우드 동기화와 분석·충돌 보고 자동 전송을 사용하지 않습니다. 광고·결제·게임즈 관련 플러그인은 활성화하지 않습니다. 게임 속 광고 업체 섭외와 금액은 시뮬레이션이며 실제 광고 시청이나 현금 결제를 뜻하지 않습니다.

백업·복원은 시스템 파일 선택기로 처리하며 광범위한 파일 접근을 요청하지 않습니다. 카메라·마이크·연락처·정밀 위치 권한을 요청하지 않습니다. Android의 시스템 백업과 기기 이전은 운영체제 및 사용자가 선택한 서비스의 설정·정책을 따릅니다.

이 안내 웹페이지는 GitHub Pages에서 제공합니다. 웹페이지를 방문할 때 연결 정보 등은 GitHub 개인정보처리방침에 따라 처리될 수 있습니다. 게임 진행을 이 웹사이트에 업로드하지 않습니다.

5. 보관·삭제와 이용자의 권리

게임 기록은 사용자가 삭제할 때까지 기기에 남습니다. 앱 설정에서 저장 슬롯을 삭제하면 해당 슬롯과 복구본을 삭제할 수 있으며, Android 설정에서 앱 데이터를 지우거나 앱을 제거해 기기의 앱 데이터를 삭제할 수 있습니다. 운영체제의 백업 설정에 따라 기록이 복원될 수 있습니다. 내보낸 백업 파일은 앱 밖에 남으므로 사용자가 저장한 위치에서 별도로 삭제해야 합니다.

개발자는 게임 계정이나 진행 데이터를 서버에 보관하지 않으므로 별도의 온라인 게임 계정 삭제 절차는 없습니다. 문의로 받은 정보는 문의 처리가 끝난 뒤 불필요해지면 삭제하며 법령상 보관 의무가 있는 경우 해당 기간을 따릅니다. 문의 정보의 열람·정정·삭제 요청은 아래 이메일로 접수합니다. 만 13세 미만 아동의 개인정보를 알고 수집하지 않으며 관련 문의도 같은 연락처에서 처리합니다.

6. 변경과 연락처

데이터 처리나 활성 기능이 바뀌면 방침과 시행일을 갱신하고 필요한 경우 앱에서도 안내합니다. 광고·결제·클라우드 기능을 도입하면 그에 맞는 안내를 적용합니다.

1. Operator and scope

YJ Studio (Google Play developer: YJ Playworks) provides the free beta of Commission: Football Agent, package com.commission.footballagent, for ages 13 and above. The game works offline without registration or account sign-in.

2. Information stored locally

The game stores the chosen agent name, careers, player and club records, virtual funds and contracts, save slots, preferences and play history on the device for gameplay, saving and recovery. It does not automatically send these records to developer servers or analytics services. A real name is not required.

3. Backups, restoration and inquiries

Exporting writes a JSON backup, including the agent name and game progress, to the location selected in the system file picker. Restoration reads only the file you choose. The app does not browse or collect unrelated files. A cloud location you select is subject to that provider's policies.

Feedback notes can include the version, mode, season, seed and your written message. Notes can be copied locally and are not sent automatically. If you contact us by email, we use your sender address and message to answer the inquiry. You do not have to attach backups or unnecessary personal information.

4. Services, advertising and permissions

This free beta does not use live ads, in-app payments, Google Play Games sign-in, app cloud synchronization or automatic analytics/crash uploads. Advertising, payment and Games plugins are not activated. Sponsorships and money inside the game are simulations, not real ad viewing or cash transactions.

Backup files are selected through the system picker without broad file access. The app does not request camera, microphone, contacts or precise location access. Android backup and device transfers follow the operating system and selected provider's settings and policies.

This policy website is served by GitHub Pages. Website connection information may be processed under the GitHub privacy statement. Game progress is not uploaded to this website.

5. Retention, deletion and rights

Local records remain until deleted. Deleting a save slot in the app removes that slot and its recovery copy. Clearing app data in Android settings or uninstalling removes local app data, although operating-system backups may restore it. Exported files remain outside the app and must be deleted separately at their selected location.

There is no online game account to delete because the developer does not host accounts or progress. Unnecessary inquiry information is deleted after resolution, subject to any legal retention duty. Contact the address below to request access, correction or deletion of inquiry information. We do not knowingly collect personal information from children under 13.

6. Changes and contact

Changes to processing or active features will be reflected here with an updated effective date and, where necessary, in the app. Advertising, payments or cloud services will require updated disclosures before activation.
