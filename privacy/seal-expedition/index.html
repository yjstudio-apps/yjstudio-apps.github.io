1. 운영자와 적용 범위

YJ Studio(이하 개발자)는 카드 RPG 봉인의 원정대(Seal Expedition)의 개인정보를 다음과 같이 처리합니다. 현재 개발·테스트 앱의 Android 패키지는 com.wallreversal.prototype입니다. 개인정보 보호 및 고객지원 담당 창구는 yjstudio.apps@gmail.com입니다.

기본 모험은 기기 저장으로 이용할 수 있습니다. 계정 연결, 클라우드 저장과 온라인 경기장을 이용하면 아래 정보가 Unity Gaming Services에 전송됩니다. 이메일 주소를 입력하는 회원가입이나 Google·Facebook 등 외부 계정 로그인은 현재 제공하지 않습니다.

3. 클라우드 저장과 다른 이용자에게 표시되는 정보

첫 클라우드 저장 또는 불러오기를 확인한 뒤 해당 계정의 자동 저장을 사용할 수 있습니다. 자동 저장을 끄면 대기 중인 기기 진행은 남으며, 이미 전송한 서버 기록이 삭제되는 것은 아닙니다. 연결한 계정으로 앱을 다시 열 때 기존 인증 세션을 복원할 수 있습니다.

경기장 상대 목록과 순위에서는 원정대 표시명, 방어 편성·전력, 포인트·순위가 다른 이용자에게 보일 수 있습니다. 현재 표시명은 플레이어 ID 일부로 만든 원정대 이름입니다. 다른 이용자에게 로그인 아이디·비밀번호나 전체 클라우드 진행을 공개하는 화면은 제공하지 않습니다. 서비스 응답에는 대전 처리에 필요한 플레이어 식별자가 포함될 수 있습니다.

4. 외부 서비스, 위탁 및 국외 처리

  • Unity Technologies 및 관련 서비스 제공자: Authentication, Cloud Save, Cloud Code, Leaderboards를 통해 인증·진행 저장·서버 검증·경기장을 처리합니다. 해당 온라인 기능을 사용할 때 위 2번의 정보와 IP 등 서비스 연결·운영 정보를 암호화된 통신으로 전송합니다. 데이터는 미국 등 Unity와 그 서비스 제공자의 운영 국가에서 처리될 수 있습니다. 국가·제공업체 등 자세한 내용은 Unity 게임 이용자 개인정보처리방침, Unity 개인정보처리방침 및 하위 처리업체 안내를 참고해 주세요. 개발자가 관리하는 계정별 정보는 아래 보관·삭제 기준을 적용하며, 제공자 자체 운영 정보에는 해당 제공자의 보관 기준도 적용됩니다.
  • Google LLC: Android에서 보상형 테스트 광고를 요청할 때 Google Mobile Ads가 통신합니다. 광고 관련 내용은 아래 5번을 따릅니다. 문의 메일은 Gmail을 통해 수신·답변하므로 발신 주소와 내용이 Google의 서비스 운영 국가(미국 등)에서 처리될 수 있습니다. Google 개인정보처리방침
  • GitHub: 이 방침과 삭제 안내는 GitHub Pages로 제공됩니다. 외부 브라우저에서 페이지를 열 때 IP 등 웹 연결 정보가 GitHub 개인정보처리방침에 따라 처리될 수 있습니다.

개발자는 개인정보를 판매하지 않습니다. 위 서비스 제공이나 법령상 요구 외의 목적으로 개인정보를 제3자에게 제공하지 않습니다. 온라인 처리를 원하지 않으면 계정을 연결하지 않고 기기 모험을 이용할 수 있습니다. 이미 보관된 서버 정보의 삭제는 별도로 요청해 주세요.

5. 테스트 광고·결제·진단 정보와 권한

현재 Android 보상형 광고는 Google의 공식 테스트 광고 ID만 사용합니다. PC에서는 실제 광고 통신 없이 보상을 시뮬레이션합니다. 테스트 광고도 Android 광고 SDK 초기화·요청 과정에서 IP 주소(대략적인 위치 추정에 사용될 수 있음), 기기·광고 식별자, 광고 상호작용 및 성능·오류 등 진단 정보를 처리할 수 있습니다. 이 정보는 광고 제공·측정·부정 사용 방지에 사용됩니다. 게임 아이디·비밀번호나 전체 게임 저장본을 광고 요청에 넣지 않습니다. Google 광고 SDK 데이터 안내 · Google 광고 안내

실제 인앱 결제는 비활성화되어 있으며 결제 수단·구매 영수증을 수집하는 상용 결제 흐름은 연결하지 않았습니다. 개발자가 별도 행동 분석 이벤트를 수집하는 분석 서비스를 활성화하지 않았으며, Unity 엔진·연결 서비스 및 광고 SDK의 운영·진단 정보는 각 제공자의 정책에 따릅니다. 실제 광고·결제 또는 추가 분석 기능을 도입하기 전에 관련 고지와 필요한 선택 절차를 갱신합니다.

게임 기능은 카메라·마이크·연락처·사진 보관함·GPS 정밀 위치를 사용하지 않습니다. 인터넷 연결은 계정·클라우드·경기장과 Android 테스트 광고에 사용합니다. IP에서 유추한 대략적 위치는 GPS 수집과 별개입니다. 광고 ID 등 기기 개인정보 선택은 운영체제의 광고·개인정보 설정에서 관리할 수 있습니다.

6. 보관 기간과 파기

기기 진행과 백업·전송 대기 기록은 앱 데이터 삭제 등 이용자가 지울 때까지 보관됩니다. 운영체제의 백업·기기 이전 및 이용자가 따로 복사한 파일에는 해당 설정·제공자의 정책이 적용됩니다. 개발자는 다른 기기나 외부에 복사한 파일을 원격으로 삭제할 수 없습니다.

계정과 클라우드·경기장 정보는 해당 서비스 제공을 위해 보유하며, 현재 일정 기간이 지나면 자동으로 삭제되는 기능은 없습니다. 본인 확인을 마친 계정·데이터 삭제 요청에 따라 해당 계정의 인증·저장본·경기장·순위·보상 기록을 삭제하거나 개인을 식별할 수 없도록 처리합니다. 로그아웃·앱 삭제·자동 저장 끄기만으로 서버 데이터가 지워지지 않습니다.

문의 정보는 문의 처리에 필요한 동안 보관하고 목적이 끝나면 불필요한 내용을 지웁니다. 법령상 보관 의무 또는 구체적인 보안·분쟁 처리를 위해 일부 보관이 필요하면 대상·사유·기간을 요청 처리 시 안내하고 해당 목적에 한해 제한합니다. 전자 정보는 서비스의 삭제 기능 등 복구·재이용을 막는 방법으로 정리합니다. 외부 제공자 자체 로그와 운영체제 백업은 제공자의 보관·파기 기준이 적용될 수 있습니다.

7. 이용자의 권리와 삭제 요청

개인정보 열람·정정·삭제·처리정지 및 계정 삭제는 yjstudio.apps@gmail.com으로 요청할 수 있습니다. 앱의 안내 → 계정 및 저장 → 개인정보·문의에서도 방침과 계정·데이터 삭제 요청 안내를 열 수 있습니다. 앱이 없어도 웹 안내에서 요청할 수 있습니다.

다른 사람의 계정 접근·삭제를 막기 위해 필요한 소유 확인을 안내합니다. 플레이어 ID나 이메일 발신 주소만으로 계정 소유를 인정하지 않습니다. 확인이 어려우면 추가 절차와 처리 가능 범위를 안내하며, 로그인할 수 없는 게스트는 복구·확인이 제한될 수 있습니다. 삭제한 진행과 재화는 되돌릴 수 없습니다.

8. 보호 조치, 아동 및 변경

서비스 통신 암호화, 계정별 접근 확인, 서버 전용 저장·성장 검증 및 관리자 접근 제한을 적용합니다. 이용자는 기기와 로그인 정보를 보호해야 합니다. 이 게임은 아동을 주된 대상으로 운영하지 않습니다. 만 14세 미만 아동의 개인정보가 적법한 동의 없이 처리된 사실을 알게 되면 법정대리인의 문의를 받아 처리를 중단하고 필요한 삭제 등의 조치를 합니다. 현재 앱에 별도의 법정대리인 동의 기능은 제공하지 않습니다.

처리 내용이 바뀌면 이 페이지와 시행일을 갱신하고 필요한 경우 앱에서도 안내합니다. 개인정보 관련 문의와 권리 행사는 YJ Studio, yjstudio.apps@gmail.com으로 연락해 주세요. 외부 권리구제 안내는 개인정보 침해신고센터와 개인정보분쟁조정위원회에서 확인할 수 있습니다.

1. App and operator

YJ Studio provides Seal Expedition (봉인의 원정대). This policy covers its current development and test version, including Android package com.wallreversal.prototype. Privacy and support contact: yjstudio.apps@gmail.com. Basic adventures use device storage. Account, cloud and online arena features communicate with Unity Gaming Services. Email registration and external social sign-in are not offered.

2. Information and purposes

Device storage contains progress, heroes, equipment, seals, parties, currencies, summons, rewards, battle and arena history, preferences, backups, pending changes and authentication sessions. These support gameplay, recovery and retrying interrupted transfers. Unity Authentication processes a player ID, guest session/tokens, an optional registered username and password authentication information, and connection information such as IP. Passwords are used for authentication, never requested through support email.

Cloud storage contains account-linked progress and preferences, save times, checkpoints, request identifiers, change and battle-reward validation information, summon results, duplicate-prevention records and earlier saves. Arena services process player IDs, defense parties, heroes, equipment and seals, opponents, results and timestamps, points, monthly ranks and reward records. These support syncing, recovery, validation, opponent discovery, server auto-battles, rankings and prevention of duplicate rewards. Support uses your sender email, message and necessary ownership-verification information.

3. Cloud and public arena information

After a confirmed first save or restore, automatic saving can be enabled for that account; an existing session may resume on reopening. Disabling sync keeps pending device changes and does not erase server records. Other players may see expedition display labels, defense parties and power, points and ranks. Current labels use part of a player ID. The game does not display login usernames/passwords or full private cloud progress to other players; service responses can include player identifiers needed for matches.

4. Service providers and international processing

Unity Technologies and its providers process the information above through Authentication, Cloud Save, Cloud Code and Leaderboards, including IP and service-operation information, for authentication, saves, validation and arena features. Online requests use encrypted transport. Processing may occur in the United States and other provider operating countries. See the Unity player policy, privacy policy and subprocessor information. Account records we control follow section 6; provider operational records also follow their policies.

Google LLC handles Android test ads and Gmail support, potentially in the US and other operating countries, under the Google Privacy Policy. This website uses GitHub Pages; web connection information is subject to GitHub's policy. We do not sell personal information or disclose it beyond service provision and legal requirements. You can avoid optional online features and play local adventures; erasing existing server data requires a separate request.

5. Test ads, purchases, diagnostics and permissions

Android rewarded ads use only Google's official test ad IDs. PC rewards are simulated without ad traffic. Initializing or requesting Android test ads may still process IP (including inferred approximate location), device/advertising identifiers, ad interactions and performance/error diagnostics for ad delivery, measurement and fraud prevention. We do not add login credentials or full saves to ad requests. See Google's SDK disclosure and ad information.

Real purchases are disabled; payment and receipt collection are not connected. We have not activated a separate behavioral analytics service. Engine, connected-service and ad-SDK operational diagnostics follow their providers' policies. Disclosures and necessary choices will be updated before commercial ads, purchases or additional analytics are introduced. Game features do not use camera, microphone, contacts, photo-library or GPS precise-location access. Internet supports accounts, cloud, arena and Android test ads. Inferred IP location is separate from GPS; manage device ad/privacy choices in your OS settings.

6. Retention and deletion

Local records remain until you remove app data or otherwise delete them. OS backups, device transfers and separately copied files follow their providers' settings; we cannot remotely erase your copies. Online account, cloud and arena records are retained to provide those services and currently have no automatic expiry. On an ownership-verified deletion request, the corresponding authentication, saved versions, arena, rankings and reward records are deleted or made non-identifying. Signing out, uninstalling or disabling sync does not delete server data.

Support data is kept as needed to resolve the inquiry; unnecessary data is deleted afterward. If specific legal, security or dispute needs require retention, we explain the data, reason and period when handling the request and restrict its use accordingly. Electronic records are removed through service deletion or other methods preventing reuse. Provider logs and OS backups may follow separate retention policies.

Request access, correction, deletion, restriction or account deletion at yjstudio.apps@gmail.com. In the app, use Guide → Account and saves → Privacy/support; the account and data deletion page also works without the app. Ownership checks protect other players: a player ID or sender email alone is insufficient. If verification is difficult, we explain the available steps and limitations; lost guest access can limit recovery. Deleted progress and currency cannot be recovered. Never email passwords, tokens, recovery codes or identity-document copies.

We use encrypted service transport, owner checks, server-only storage/validation and restricted administrative access. Protect your device and credentials. The game is not primarily directed to children. If we learn that information of a child under 14 was processed without required consent, we address guardian requests and stop processing or delete it as appropriate. This version has no separate parental-consent feature. Changes appear here with an updated effective date and in-app notice where required. Contact YJ Studio at the address above.
