집기록

보증금 지키는 우리집 증거함

비공개 테스트 준비 중

세입자가 입주할 때 집 상태를 사진으로 남기고, 퇴거할 때 같은 구도로 다시 찍어 비교하는 앱입니다.

  • 입주 사진을 반투명하게 띄워 같은 구도로 다시 찍기
  • 찍은 뒤 '정상 / 문제있음'만 고르는 빠른 기록
  • 문제 발견 → 집주인 알림 → 수리까지 이어지는 사건 타임라인
  • 원본 사진 그대로 담는 증거 PDF, 기기 안에서 읽는 계량기 숫자
